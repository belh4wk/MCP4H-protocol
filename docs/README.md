For the current project definition and architectural direction, start with:

The 2025 manifesto and whitepaper remain important historical foundation documents, but they are no longer the sole description of the active architecture.

Current MCP4H work has moved beyond a fixed four-modality interpretation, mandatory text-first semantics and the original "4-Point Harness" metaphor as an architectural definition.

The `4` in MCP4H means **For**.

Historical publications and citation titles remain unchanged for archival and DOI integrity.

Van Echelpoel, D. (2025). *MCP4H™: The 4-Point Harness of Communication - A Human-First Multimodal Protocol (Initial Draft: Manifesto + Whitepaper).* Zenodo. https://doi.org/10.5281/zenodo.17164550

That title is preserved verbatim as a historical citation. It should not be read as a current requirement that MCP4H contain exactly four carriers.

## Versioning

The current tagged compatibility baseline is **v0.1.5**.

The next architecture cycle is **v0.2**, beginning with foundation and schema design work rather than silently changing v0.1.x semantics.
